# Universal Mentor Lab

Static GitHub Pages dashboard containing 18 interaction prototypes derived from
the July 2026 research synthesis.

The demos are deliberately browser-local: they demonstrate product behavior,
control flow, shared contracts, graceful degradation, and learner ownership
without pretending to call production models or store real learner data.

## Capability coverage

| Prototype | Research method demonstrated |
|---|---|
| Mentor conductor | Explicit `TeachingAction` selection and reason |
| Live multimodal mentor | Full-duplex voice, page, gesture, interruption, and modality pivot |
| Expert mentor mesh | Role-certified specialist routing |
| Verified knowledge compiler | Source → `ConceptSpec` → representation → verification |
| Learner-owned state | Portable, correctable, uncertain longitudinal state |
| AI-native textbook | Learner-specific compiled micro-chapter |
| Reactive learning document | Shared variables update visual, equation, narration, and probe |
| Verified visual generator | Truth, render, accessibility, and provenance checks |
| Assessment evidence engine | Activity → response → explanation → performance → transfer |
| One concept, four depths | Invariant-preserving explanation ladder |
| Memory that compounds | Encode, retrieve, repair, vary, space, and connect |
| Compassionate persistence | Purpose, action, challenge, progress, and shame-free return |
| Teach, build, collaborate | Learner-authored create, defend, revise, and transfer loop |
| Worlds you can question | Generated world grounded by executable laws and observation |
| Screen-to-world mentor | See, sense, coach, connect, and permission-gated actuation |
| Accessibility-first pivot | Preserve goal while composing the access path |
| Offline-first continuity | Device, community-hub, and regional/cloud tiers |
| Human handoff | Minimum context, bounded authority, and learning continuity |

## Local preview

Serve the repository root or `docs/` with any static HTTP server. Opening the
HTML directly also works for most interactions, but a server reproduces GitHub
Pages paths more accurately.
