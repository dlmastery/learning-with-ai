Demo Gallery

Every technique, running

A survey that only describes techniques is a reading list. All fourteen demos here run in your browser — no server, no key, no sign-in — and each states plainly what it proves and what it merely illustrates.

Every demo on this page is computed: it performs the operation rather than replaying a transcript. The grounding ladder really runs its checks and really times them; the pāṭha protocol really permutes and really detects. Where a mechanism needs a model we cannot ship in a static page, the page says so on itself, above the fold. None of them are dressed up as measurements.

The caveat that applies to all of them. A demo shows that a mechanism is buildable and coherent. It is not evidence that it teaches. The evidence lives in the survey, the effect sizes are on the dashboard, and several of these techniques have never been tested against a proper control — which is stated on the pages where it's true.

The village

Seven roles demonstrated here. The full registry is ten, and the number that governs design is the active set of 3–5 per learner-hour — the economics permit about forty, the orchestration evidence permits three to five.

What none of these are

They are not products, not a curriculum, and not evidence of learning gain. They exist so that a reader can disagree with a specific thing rather than with a description of a thing. Every demo links back to the research report it came from, and every report is in research/raw/ with its sources.
