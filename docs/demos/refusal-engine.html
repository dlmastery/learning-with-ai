The Mentor That Won’t Tell You

Most tutoring systems hide the moment where they decide to help. This one puts the decision function on the table. Move the inputs; watch answer / ask / wait / pivot / escalate change, and read the exact rule that fired.

Computed live Guardrails remove harm, add nothing Wording is templated
What this is

The decision function of a tutor that would rather ask than answer, with every input exposed as a control. Move a slider and the verdict — answer · ask · wait · pivot · escalate — recomputes, along with the rule that fired.

Why it matters

Unguarded AI leaves learners 17% worse on later unassisted work. Guardrails measurably remove that harm (unassisted coefficient −0.004, n.s.). They have not been shown to add benefit. Restraint is the one thing no vendor ships and the one thing the evidence demands.

How to use it

Set attempted to no and watch every branch refuse to answer. Then switch the learner to explicit-instruction mode and see the logic invert. For that learner, withholding is the harm.

COMPUTED — with one labelled exception. The decision itself is a real, ordered rule evaluation running in your browser; every predicate below is executed against the inputs you set, and the trace shows which rules were tested and which one fired. The sentence the mentor speaks is a fixed template chosen by the decision. It is not generated, and it is not evidence that a model would say anything similar.

Bastani et al., PNAS 2025. ~1,000 high-school students, ~50 classrooms, 4 × 90-minute sessions ≈ 15% of the curriculum. MEASURED-RCT. The 2025 PNAS notice attached to this paper is an affiliation erratum; the −17% stands.

Read the second row honestly. The guardrailed coefficient is −0.004, not significantly different from zero. The correct sentence is “restraint removes the harm; it does not add a benefit.” Anyone who quotes this trial as evidence that a well-designed tutor teaches is quoting the row above the one that matters. And it is one school, in one country, not yet replicated.

What this proves / what it does not

What it proves
  • The help/withhold decision can be made legible. A finite, ordered, inspectable rule set replaces a vibe emitted by a prompt.
  • Every input is one a real system can observe without inferring a diagnosis, an emotion, or a disability label.
  • The SELPA inversion is a genuine structural property rather than a slogan: identical inputs, two modes, different actions. The mode itself is a declared setting, never something the system guesses about a child.
  • Escalation to a human is a first-class outcome with its own firing rule, not a fallback for when the model fails.
What it does not prove
  • That these thresholds are right. 45 seconds, 0.85, three repeats are design proposals rather than measured optima. No trial has calibrated them.
  • That the inputs are measurable at this fidelity. “Frustration signal” is a slider here; in production it is an inference, and inferring affect from keystrokes has a poor track record.
  • That withholding teaches. The guardrailed arm of the only RCT with an AI-removed exam returned n.s. Restraint is defensible because the unguarded alternative measured −17%, not because restraint measured a gain.
  • That the templated sentences would survive contact with a real model. Selection is computed; the words are canned.
