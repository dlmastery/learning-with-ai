Set an access profile, expose a misconception, route a specialist, change representation, remove help, teach the idea back, and schedule its return. The learner operates one lesson; the system coordinates the faculty.

What

A state machine joining six mechanisms that the gallery previously showed separately.

Why

A school in a box is the control loop between capabilities. A directory of clever agents leaves the coordination work with the learner.

How

Your answers update explicit learner state and determine the next representation. Refreshing resets everything; no data leaves this page.

What this proves: the workflow, state transitions and routing rules are executable in one interface. It does not prove learning efficacy. The active-control experiment is this loop against a token-matched frontier tutor on delayed, unassisted, novel items.
