# Process

Backstage. Not the work — the record of how the work was run, kept because a survey
that hides its own method is asking for trust it has not earned.

| File | What it is |
|---|---|
| [`PRD.md`](PRD.md) | The original research plan: 30 sections, the editorial standard, the anchoring-risk mitigation |
| [`AUDIT.md`](AUDIT.md) | A requirements audit written against ourselves on 27 July. **Superseded** — kept as a record of what was true that day, not as a status page |
| [`ASSUMPTIONS.md`](ASSUMPTIONS.md) | **Every framing decision made without asking, and which ones were wrong.** Written after the owner said *"think bigger"* four times and each was patched locally instead of read as a frame error |
| [`CLAUDE.md`](CLAUDE.md) | The working ledger: requirements, standing corrections, resume procedure. Exists so the project survives a crash |
