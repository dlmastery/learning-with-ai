# Vision gap audit

Acceptance source: `TASK.md`, Part A and founding ask 1. The product is a
personalised school and university in a box: frontier AI makes an expert agent
faculty available to every learner, including a child served by a SELPA plan. It
should compress orientation and explanation without pretending that durability can
be compressed away.

This audit judges the repository against that destination, not against the amount of
research already collected.

| # | Required system property | What existed | Gap | Repair |
|---|---|---|---|---|
| G1 | One coherent university/school in a box | Strong individual sections and 27 mechanism demos | No artifact showed the whole operating loop | Add the operating-system section and an end-to-end `university-in-a-box` demo |
| G2 | Persistent learner model that changes instruction | Learner-model and pivot demos | No visible state carried across a complete lesson | Make diagnosis, modality, method, evidence and next session one continuous stateful journey |
| G3 | Agent village of exceptional specialists | Village section and roster demo | Roles were a directory, not an orchestration protocol | Show routing, disagreement, handoff, shared state, budgets and escalation in the integrated architecture |
| G4 | SELPA-first access, not a sidebar | Empty Chair, reading, attention and coordinator sections | Accommodations were distributed across the paper and absent from the main product experience | Put access profile, decoding load, response mode, chunking and executive-function support in the first-run flow |
| G5 | Live multimodal presence | Frontier substrate research | Voice/video appeared as capability inventory, not the default interaction surface | Specify interruptible speech, camera/shared-work input, pointing, captions, transcript and low-bandwidth fallback |
| G6 | Generated worlds and simulations | World-model references and manipulation demos | No rule for when a generated world teaches better than a diagram or symbolic tool | Add a representation router with verification and learning-objective gates |
| G7 | On-demand textbooks, slides, animations, notebooks and video | Separate sections on textbooks and showing | No common lesson compiler or provenance path | Define one compiled lesson graph with multiple verified renderers |
| G8 | Elite explainer craft across domains | 104-technique inventory and explanation atlas | Inventory did not drive the learner-facing path | Route methods by concept obstacle and measured learner response, not style preference |
| G9 | Teach-to-learn and bidirectional learning | Teachable-agent demo | Not a graduation gate in the core loop | Require learner explanation, adversarial questions and correction before mastery advances |
| G10 | Executive-function replacement | Attention section and stuck detector | Reminders and rescue were not integrated with instruction | Make initiation, time estimation, checkpointing, restart and handoff first-class agent duties |
| G11 | Ecosystem of publishers, authors and creators | Strong thesis chapters | Product surfaces still looked like a closed corpus | Make source rights, provenance, author intent, item telemetry and revenue-sharing explicit interfaces |
| G12 | Accessible frontier capability at token economics | Economics analysis | Accessibility, offline/low-bandwidth delivery and cost budgets were not one design constraint | Add a modality/cost/access budget to every compiled lesson |
| G13 | Recursive improvement grounded in learning | Open-problem agenda | Research loop was detached from product behavior | Every pedagogical policy gets a version, outcome, subgroup analysis and rollback path |
| G14 | Polymath compression from zero to hero | Compression section and ELI ladder | No cross-domain curriculum composer or prerequisite scheduler | Add a goal-to-graph compiler spanning concepts, projects, checks and durable review |
| G15 | Positive, future-led posture | Mission-led deck; evidence-heavy dashboard and README | The main surfaces still spend most of their visual weight on why current systems fail | Lead with the system, its learner journey and frontier capability; retain falsifiers as engineering discipline |

## Definition of done

The sweep is complete only when:

1. A new reader can describe the whole product after the first screen.
2. A learner can run a coherent first-session demo rather than browse mechanisms.
3. The paper names the architecture, contracts and control loop in one place.
4. The deck shows what happens in a learner hour, not only market and evidence.
5. The dashboard makes every major frontier capability visible and connects it to a
   learning decision.
6. SELPA and executive-function support are present in the core path.
7. All claims still distinguish measured results, available capability, design and
   hypothesis.
